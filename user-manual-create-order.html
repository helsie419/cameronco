Creating an Order

Use this guide when entering a new customer order, insurance claim, quote, or workshop job in the Cameron & Co CRM. In the system, an order starts as a quote or claim. Once approved, it becomes a job on the Job Board.

Before You Start

Collect the key information before creating the order.

  • Customer name and contact details
  • Insurer name, if this is insurance work
  • Claim number or internal reference
  • Item details, including metal, stones, dimensions, and description
  • Pricing or costing details for each item
  • Any policy limits, excess, salvage, or settlement notes

1. Select or Create the Customer

  1. Open Quotes and click New quote — or click Add customer from the Customers screen, which opens the same page.
  2. Paste from insurer portal (optional): if you have the claim copied from the insurer's portal, paste it into the box at the top and click Extract details. It fills in name, address, phone, email, and — where the pasted text includes them — claim number, insurer, and reference. It matches on labelled lines (e.g. "Claim Number:", "Insured:"), so it won't catch every portal layout perfectly — a summary shows what it matched, and everything is still editable.
  3. Otherwise, in the Customer section, search by name, email, or phone.
  4. If the customer appears, select the existing customer.
  5. If the customer does not appear, enter the customer details and click Continue with this customer.
  6. Possible duplicate warning: if the name and address you've entered closely match an existing customer, a banner appears showing that customer's name and address. Click Use this existing customer to link to them, or dismiss the warning if it's a different person with a similar name.
Important: Always search first (or check the duplicate warning). One customer can have many claims or orders, so avoid creating duplicate customer records.

2. Enter Claim or Order Details

Complete the Claim details section. These details become the order header.

  • Insurer: select the insurer, or leave as private/no insurer.
  • Insurer contact: choose a contact if applicable.
  • Claim number: the insurer's claim number. For private/retail work with no insurer selected, this field greys out and fills itself automatically from Our reference below — there's nothing to type here in that case.
  • Date received: enter the date the work was received.
  • Our reference: Cameron & Co's internal reference. Leave blank on a new claim and it's generated automatically (e.g. CC-2026-0001) — the prefix, digits, yearly reset, and starting number are configurable in Settings > Internal Reference Numbers.
  • Insurer reference: enter a separate insurer reference if needed.
  • Assessment type: select the request type.
  • Validation type: select the validation type.
  • Branch: choose Melbourne or Sydney.
  • Assessed by: select the staff member responsible.
  • Policy excess: enter any policy excess.
  • Settlement note: add special instructions, such as "Refer case manager".
Required: The customer must be selected/created before the record can be saved. Claim number is required for insurer work; private work fills it in for you.

3. Add Items

  1. Complete the first item card.
  2. Select the item Category and Item type.
  3. Add the description that should appear on the quote.
  4. Enter item specifications, such as metal, colour, manufacture origin, weight, ring style, chain style, length, width, finger size, repair type, and internal comments.
  5. For watches, complete the watch details section.
  6. To add another item, click Add item.

4. Add Stones

For each item, use the Stones table to record relevant stone details.

  • Stone type
  • Shape
  • Quantity
  • Carat each
  • Total carat
  • Quality
  • Certificate details
  • Cost per carat
  • Total stone cost

Only add stone rows that are relevant to the item.

5. Add Costing

Use the costing area on each item to calculate the item price.

  • Metal or chain rate
  • Weight in grams
  • Setting tier and quantity
  • Casting
  • Labour hours
  • Box and valuation
  • Stone costs

The CRM calculates retail amount, insurance nett, and liability. Check the totals before generating the quote.

6. Enter Settlement Details

In the Settlement breakdown section, enter any extra settlement figures.

  • Postage, handling, and insurance
  • Salvage or scrap allocation
  • Overall unlisted policy limit, if applicable

The totals bar shows the number of items, total retail including GST, insurance nett, and liability with limits applied.

7. Save or Generate the Quote

  • Click Save draft if the order is not ready to quote.
  • Click Generate quote when the quote is ready.

Generating a quote saves a quote version and snapshots the current rates and metal spot prices. If pricing changes later, the generated quote keeps the rates used at the time.

The claim moves to Pending approval — it cannot be emailed yet. On the Quotes pipeline, an admin picks themselves under Approving as and clicks Approve (use PDF first to check it). Only then does Email quote become available to send it to the customer.

8. Find the Quote Later

  1. Go to Quotes.
  2. Use the search field to find the claim number, customer, or insurer.
  3. Use the status filter if needed.
  4. Click Open to return to the quote.

9. Approve the Quote

Before an order can become a workshop job, the quote must be approved.

Current note: The backend supports approved quotes and approved claims, but the current visible screens do not yet show a dedicated "Approve quote" button. Until that button is added, approval may need to be completed by an admin or through the existing backend process.

Once the claim status is Approved, it can be turned into a job.

10. Create the Workshop Job

  1. Open Job Board.
  2. Click Create job from an approved claim.
  3. Find the approved claim in the list.
  4. Click Create job.

The CRM creates a job and copies the claim and item information across. Staff do not need to re-type the order details.

Complete Job Details

  1. Click the job card.
  2. Set or update the stage, owner, start date, due date, and items taken.
  3. Review the component lines.
  4. Add supplier, stock number, invoice number, weight, rate, and actual cost as needed.
  5. Click Save changes.

The job card shows the current margin based on quoted nett minus actual component costs.

Common Problems

I cannot save the quote

  • Check that a customer has been selected or created.
  • Check that the claim number has been entered.
  • Check that address fields are complete if an address was started.
  • Check that the database/API connection is working.

The approved claim does not appear on the Job Board

  • Check that the claim has an approved quote.
  • Check that the claim status is approved.
  • Check that a job has not already been created for that claim.

The pricing looks wrong

  • Check item weight, metal or chain rate, setting quantity, labour hours, and stone cost.
  • Check policy limits, salvage allocation, and current rate card values.

Good Practice

  • Search for the customer before creating a new record.
  • Use clear item descriptions because they appear on the quote.
  • Save drafts while gathering missing information.
  • Generate a new quote version when pricing changes.
  • Keep job stages current.
  • Record actual component costs as invoices arrive.
